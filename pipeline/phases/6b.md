PLAN refs: §2, §9 (/admin), §13 (latest state per user query).

## Classifier comparison page (PLAN §8.7/§8.8 — owner decision 2026-10-04)
- **Page:** `/admin/classifiers` (master only, server-enforced), backed by phase 5b's `GET /api/v1/comparison/classifiers` and `/comparison/derivers`. If they aren't on main yet, code against the contract in pipeline/phases/5b.md and mock them in your tests.
- **Table:** one row per classifier: id, description, default badge, votes up/down, agreement rate, and the backtest hits, misses and false alarms. Add a date-range selector.
- **Promote:** a "Make default" action with a confirmation that explains what users will see change.
- **Derivers:** a read-only list with the default badge.
- **Variant switch:** in the athlete drill-down, a selector to view any classifier's trends for that athlete (via `?classifier=`), clearly labelled when it isn't the default.
