Security and infra:

  app read it at runtime instead, so it is not in build artifacts.
- `apps/api/src/lambda/bootstrap.ts` connects with `sslmode=no-verify`. Add an `ssl` option to
  `apps/api/src/users/pool.ts` that verifies the server against the RDS CA bundle, and use it.
- Every Lambda shares the Aurora master credential, which deviates from PLAN §11 (webhook Lambdas:
  write only). Add per-function Postgres roles with the least privileges each handler needs, or
  document precisely why not. The master password has no rotation; add it or record the risk.

  it in `infra/cdk/DEPLOY.md`.

  configurable retry cap (CLAUDE.md rule 9) and a terminal status.
- The cost figures in `infra/cdk/README.md` were written from memory. Fetch current AWS pricing
  (WebFetch) and cite the URLs in docs/COST.md; correct the README where it is wrong.
